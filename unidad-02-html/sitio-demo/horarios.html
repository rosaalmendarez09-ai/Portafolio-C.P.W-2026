    • Cómo entregar una práctica

    1. Traer los cambios con git pull
    2. Crear la rama para la práctica con git switch -c "nombre de la rama"
    3. Trabajar y hacer commits atómicos
    4. Subir la rama con git push
    5. Abrir un pull request en GitHub
    6. Revisar y fusionar el pull request
    7. Volver a la rama principal main
    8. Eliminar la rama de la práctica con git branch -d "nombre-de-la-rama"

    Glosario Git con listas descriptivas

    Commit
    Instantánea permanente del proyecto en un momento dado
    Rama
    Línea de trabajo paralela que no afecta a main o rama principal
    Pull
    Solicitud de revisión para incorporar la rama
